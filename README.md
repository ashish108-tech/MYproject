# DigiHealth

AI-Powered Integrated Healthcare and Home Diagnostic Assistance Platform for Rural, Semi-Urban and Urban Communities.

## Phase 1 — Foundation
Next.js + TypeScript App Router foundation with Tailwind CSS, Lucide icons, responsive landing page, role placeholders and API configuration documentation. Authentication, database, AI, RAG and healthcare workflows are intentionally deferred to later phases.

## Run locally
```bash
npm install
npm run dev
npm run typecheck
npm run build
```

Copy `.env.example` to `.env.local`. Never commit real secrets.
